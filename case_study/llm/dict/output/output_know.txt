OUTPUT TOKEN SIDE-CHANNEL — DICTIONARY DESIGN NOTES
================================================================================

목적
----
VLM(Qwen2-VL-2B-Instruct)이 생성한 출력 텍스트의 첫 문장을
SEV-SNP ciphertext 비교로 식별한다.

모델은 greedy decoding(do_sample=False, num_beams=1)을 사용하므로
동일 입력에 대해 출력이 완전히 결정론적이다.
→ 한 번 캡처한 ciphertext는 이후 동일 샘플에 항상 재사용 가능.


왜 첫 문장을 타겟으로 하는가
-----------------------------
output_dict.txt 분석(3463 샘플)에서 첫 문장이 소수의 고빈도 패턴으로
수렴함을 확인:

  283  "The chest x-ray in the image shows a normal chest with no visible abnormalities."
  122  "Based on the chest x-ray provided, the following findings can be observed:\n\n1."
  107  "The chest x-ray in the image shows a normal chest with no obvious abnormalities."

첫 문장이 결정되면 이후 내용도 대부분 예측 가능(deterministic).
"정상 vs 비정상" 판단을 위해 이 3개 구문이면 충분.

제외한 구문:
  436  "Here are the key findings:\n\n1."
  71   "The chest x-ray in the image shows a few notable findings:\n\n1."
→ 소견이 있다는 사실만 알 수 있고 내용이 없어 의미 없음.

ICMP 기반 사전 구축 원리
------------------------
orchestrate_v2.py의 indication 사전과 동일한 메커니즘:

1. payload = b'\x00' * prefix + (token_bytes * repeat)[:4097+]
   token_bytes = struct.pack("<Nq", *token_ids)  (little-endian int64 × N)

2. prefix를 조정해 token sequence가 page 내 특정 offset에 정렬되도록
   2-probe delta 측정 → expected_frag → prefix 계산

3. 게스트 ICMP 수신 모듈이 GPA를 dmesg에 기록
   → 호스트가 파싱 → read_gpa.py로 4KB 페이지 ciphertext 덤프 저장

4. 한 번의 덤프가 해당 페이지 내 L-byte 간격 모든 offset을 커버
   (L = len(token_ids) × 8)

총 전송 횟수: 49 phases × 3 sends = 147 ICMP packets

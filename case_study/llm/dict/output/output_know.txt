================================================================================
OUTPUT TOKEN SIDE-CHANNEL — DICTIONARY DESIGN NOTES
================================================================================

Objective
---------
Identify the first sentence of generated output text from VLM (Qwen2-VL-2B-Instruct)
via SEV-SNP ciphertext comparison.

Since the model uses greedy decoding (do_sample=False, num_beams=1),
outputs are completely deterministic for identical inputs.
-> Ciphertext captured once remains valid and reusable for matching samples.


Why Target the First Sentence
------------------------------
Analysis of output_dict.txt (3,463 samples) shows the first sentence
converges to a small set of high-frequency templates:

  283  "The chest x-ray in the image shows a normal chest with no visible abnormalities."
  122  "Based on the chest x-ray provided, the following findings can be observed:\n\n1."
  107  "The chest x-ray in the image shows a normal chest with no obvious abnormalities."

Once the first sentence is determined, subsequent text is largely predictable.
These 3 phrases suffice to distinguish "normal vs abnormal".

Excluded phrases:
  436  "Here are the key findings:\n\n1."
  71   "The chest x-ray in the image shows a few notable findings:\n\n1."
-> Only indicate existence of findings without descriptive content.

ICMP-Based Dictionary Construction
-----------------------------------
Identical mechanism to the indication dictionary in orchestrate_v2.py:

1. payload = b'\x00' * prefix + (token_bytes * repeat)[:4097+]
   token_bytes = struct.pack("<Nq", *token_ids)  (little-endian int64 x N)

2. Adjust prefix so token sequence aligns to specific in-page offsets
   2-probe delta measurement -> expected_frag -> compute prefix

3. Guest ICMP monitor records GPA in dmesg
   -> Host parses GPA -> read_gpa.py dumps 4KB page ciphertext

4. A single dump covers all offsets at L-byte intervals in that page
   (L = len(token_ids) * 8)

Total transmissions: 49 phases x 3 sends = 147 ICMP packets
